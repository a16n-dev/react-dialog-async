# React Dialog Async Docs

This project contains the documentation website for React Dialog Async V3, built with [VitePress](https://vitepress.dev) and styled with the [Hazel](https://hazel.a16n.dev) theme.

```sh
pnpm dev      # start the dev server
pnpm build    # build to .vitepress/dist
pnpm preview  # serve the production build
```

If you are looking for the V2 docs, please see the [docs-v2](../docs-v2) package.
